# BHIL build checklist

Use the method as a quality bar, not as a costume. Run this list on every
artifact before it ships.

## Argument

* [ ] Headline states the answer, not the topic.
* [ ] The first paragraph contains a measurable tension or claim.
* [ ] Frameworks arrive after enough evidence exists to justify them.
* [ ] The close gives a small set of actions.

## Exhibits

* [ ] Each exhibit has one dominant point.
* [ ] Exhibit titles are full-sentence findings.
* [ ] Chart type matches the question being asked.
* [ ] Direct labels are used where they reduce scan time.
* [ ] Color is limited to a small functional palette.
* [ ] Source lines appear on every data exhibit.

## Method and honesty

* [ ] Method notes define sample, period, and weighting where relevant.
* [ ] Forecasts and self-reported outcomes are visibly qualified.
* [ ] The document has a consistent byline and ownership model.

## Fit and identity

* [ ] Short articles stay text-led; survey reports carry more exhibits.
* [ ] Original names and visual identity are used throughout.
* [ ] Nothing copies exact logos, trademarked framework names, exact page
      layouts, or exact trade dress.

## Final test

Can a busy executive understand the point, see the proof, and find the
method without hunting? If yes, ship. If no, the failing checklist line
above tells you which chapter of the field guide to reread.
