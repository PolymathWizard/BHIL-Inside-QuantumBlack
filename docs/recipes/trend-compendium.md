# Recipe: trend compendium

Map the landscape, score what matters, and draw implications. Four moves,
modeled on the scored-chapter compendium format.

## The skeleton

1. **Framing intro.** Set the context and why it matters now, one or two
   pages, no throat-clearing.
2. **Methodology box.** Explain how trends were identified and scored:
   the vectors, the scales, the data sources, the cut lines. Fix this in
   edition one; it is the spine of the franchise.
3. **Scored trend chapters.** Repeatable format with consistent
   structure: definition, scores, use cases, talent signal,
   uncertainties. Every chapter behaves identically so the reader can dip
   in anywhere.
4. **Cross-cutting implications.** Synthesize what it means for different
   stakeholders, the only section allowed to reach across chapters.

## Density budget

Dense and modular: dozens of scorecards, each self-contained at a fixed
size. The scorecard is the exhibit; design it once, run it everywhere.

## Scoring discipline

* Publish the rubric before the scores.
* Score every entry on every vector, no blanks.
* Keep the scale stable across editions so deltas mean something.
* Mark judgment calls as judgment, a scored compendium is still an
  argument, not a measurement.

## Guardrail

Original trend taxonomy, original scoring vector names, your identity.
The observed compendium's scale and vector design are recorded as
structure; the names are not yours to reuse.

## Acceptance test

Hand a reader one chapter with the intro removed. If they can read it
cold, the modular promise holds. Then check two chapters side by side; if
any section order differs, the format has drifted.
