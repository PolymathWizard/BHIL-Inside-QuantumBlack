# ADR-001: The source register CSV is the single source of truth

## Status

Accepted.

## Context

The source register appears in three places: the research artifact, the
branded appendix document, and this repository's docs site. Hand-editing
any rendered copy invites drift between them, and drift in an evidence
register is worse than drift anywhere else because downstream claims cite
row IDs.

## Decision

`data/source_register.csv` is canonical. `docs/registry/source-register.md`
is generated by `tools/generate_register_page.py` and hashed into
`data/drift_manifest.json`. CI fails on any mismatch. Edits flow: change
the CSV, run the generator, refresh the manifest, commit all three.

## Consequences

Contributors cannot fix a typo in the markdown directly, which is mildly
annoying and entirely the point. The validator additionally pins tier and
taxonomy roll-ups so a data edit that changes the evidence picture fails
loudly until the ledger is updated too.

## Open questions

1. Should the branded appendix docx also be generated from the CSV?
   Settling criterion: adopt when the docx is regenerated more than twice
   per quarter; a second generator is not worth its maintenance below
   that rate.
2. Should register rows carry an Admiralty grade column in addition to
   the STENCIL tier? Settling criterion: add it when a downstream
   consumer needs machine-readable reliability grades; today the grade is
   derivable from access class.
